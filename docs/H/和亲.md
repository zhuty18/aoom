# 和亲

赵匡胤接了一笔买卖，要护送南唐公主去东都开封和亲。

是武侠pa，所以不符合历史的地方很多、很多……

01

半年以后，当弟弟看着天家下聘的热闹，问起这一路的经历时，赵匡胤一时竟不知从何说起。

思量半晌，他终于捡定了一个起点，道：“一开始，我也没想到会是眼下这么个情况——那会子刚过立秋，有天天上黑压压的，飘着点小雨，不知道什么时候就要下大。我看不方便走太远，就在客栈不远处挑了个茶棚喝水……”

说来也怪，旁边搭台卖艺明明热闹得紧，这间能遮风挡雨，又有鲜爽银豪可喝的茶棚却空空荡荡。除去赵匡胤和烹茶的小厮，只有一个人。

赵匡胤望过去时，那人也在打量赵匡胤。一双黑白分明的眼睛落在少年游侠身上，从头看到脚，从脚看到头。一只白瓷的盏被端在唇边，釉色澄净，更衬得他的眉眼深不见底。

他与赵匡胤对上眼神，笑了一下，端着茶走了过来。赵匡胤忽然有点没来由的紧张，没想清缘故，那人就在他身边坐下了。

赵匡胤先闻到他外袍上凉飕飕的龙脑香，又瞧见他袍袖上的竹叶暗纹，正为此人的富贵程度暗暗吃惊，就听到他说话，声音清冽得像用新竹的嫩叶撩起一寒潭的静水。

“……如何？”赵匡胤看到对方朝他靠了一寸，问道。

赵匡胤错开眼神，颇感丢人：“对不住，我没听清，能再说一遍吗？”

“我说——这位小兄弟，我看你剑眉星目，一表人才，有心给你说个前程，不知你意下如何？”

一个那，那样的人，怎么说出的是这样的话？赵匡胤心里一滞，只觉得眼前有片朦胧的雾色凭空碎掉了。

抬眼再看时，却又觉得好像什么也没变，这个富贵公子仍含着笑看他，几根蜷在他额角的头发在空气中轻轻摆动。

赵匡胤几乎就要开口答应。临了猛地清醒过来，探问：“不知是何处的前程？”

这人极慢极慢地一笑，盯着他的眼神志在必得，道：“河中郭令公。”——中原刘汉的枢密使郭威。几月前赵匡胤还在开封时，曾见他出征河中剿叛军，竟打到了现在么。

若说不意动，自然是骗人。郭威深通兵法韬略，实乃国之栋梁，更兼身负从龙之功，深受官家信爱，若得他赏识，平步青云封侯拜将也绝非妄言。但……

赵匡胤叹气：“兄长美意，本不应辞。郭令公一世英雄，我也仰慕已久。但我眼下……回不得北边。”

“哦？却是为何？”这人说着，又往他身边探了探身，一副关切的模样，“若是盘缠不够，只管说就是。愚兄经商之人，手边银钱总是够用的。”

“倒也……不是盘缠的事。”赵匡胤跑出来时可没委屈了自己，在家中颇一番翻箱倒柜，把他爹的私房钱搜出满满一大包上的路，粗粗一算够花到明年。

他看着对方的不解的眼睛，重重一叹，道：“实不相瞒，开封城中太子沉溺声色犬马，荒废学业。我爹劝谏太子几句，让他着人打了一顿棍子。我一时激愤，便想去他那勾栏讨个说法，摸进去时，听见那班乐师计较着怕我父子寻仇，想把我爷俩骗进去杀了。我一时怒上心头，就把那班御乐杀了个精光。本想着连太子一起结果，但天色已亮，来不及等他，只好先跑了。——眼下，多半北边正发榜通缉我哩。”

那人听得一愣又是一愣，缓缓道：“……竟有此事。”

赵匡胤本以为他会说点什么，这人却眼睛一眨，将诸般打算都收了起来，只看着赵匡胤，柔声道：“弟弟遭了这无道太子，有家回不得，几千里逃至这寿春城，想必心中委屈得紧。”

赵匡胤原没觉得有什么委屈，不过是想到回家必挨上老爹一顿揍，有些头痛。让他这样一哄，忽然心中诸般酸涩全凭空冒了出来，张了张嘴，不知说什么好。

那人握住他的手，道：“我实在爱惜你的人才，不如这样，你跟了我去。愚兄姓柴，是个行商，此行去金陵卖茶，而后便回河东，届时我亲自送你到郭令公帐下。你只管跟着我，我有郭令公的信物，谅也无人敢来查。”

赵匡胤垂下目光看了一眼他的手，手指头细细的长长的，比他这习武之人白上一个号。移开眼神，飘飘忽忽地道：“我跟着你……那还去郭令公帐下作甚？”

见对方失笑，赵匡胤又道：“我看哥哥丰神俊朗，龙章凤姿，比远在天边的郭令公可靠得多。我这前程，落在哥哥手里就是了。”

柴老板长眉微挑：“你想做我的入幕之宾？”

赵匡胤点头：“哥哥放心，我必不是那吃闲饭的。——我叫赵匡胤，东京人氏，家住双龙巷，父亲是殿前都指挥使赵老爷讳弘殷……”

“好了，”柴老板不轻不重捏捏他的手，“我是看中了你，又不是看中你祖宗十八代。”

赵匡胤尴尬地直喝茶，柴老板又上上下下打量他一番：“你有字没有。”

赵匡胤摇头道：“弟弟今年才一十九岁，未及加冠，没得那些字啊号啊的给人叫。哥哥要叫，就叫我我玄郎吧，这是我小名，”

柴老板便问：“不知弟弟几时生辰？”

“二月十六。”

柴老板点点头：“那好，明年二月十六，如不嫌弃，哥哥为你加冠取字。”

赵匡胤感觉自己脸都红了。半晌才道：“还、还未请教哥哥名姓。”

柴老板拍拍他的手背：“我今年二十五岁，长你六岁，做你哥哥想还做得？你叫我柴大哥就是了。”

赵匡胤便有些不快，明明是柴老板来勾引他的，可却连名字也不肯告诉他一个。他驳斥道：“哥哥连名字都不可说，做弟弟的怕哥哥不是真心与我交往。”

柴老板失笑
