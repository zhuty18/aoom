# 喜欢的是你又不是你的脖子

精神状态接近李火旺的钰x厉鬼谦

真的是厉鬼

<br>

那一刀劈下来时，天地变色。

京城正月里素来是漫天白云，十天半月未见得有一缕青天，在这一刻却有无源之风席卷六合，搅碎愁云惨雾。覆盖京城的云霭自法场上空撕裂，露出无边晴空的一角，浅金色的阳光抚过他闭不上的眼睛，仿佛天地神灵落下的一个轻轻的吻。

风停了。厚重的阴翳卷土重来，刹那间已经掩住满城血气，灰压压地笼在头顶上，白日里渗出几份昏昏暮色，似乎冥路将近。

不知人群中哪一个开口，尖锐到凄厉的声音便幽幽飘上九天：“……委实的冤情不浅，若没些儿灵圣与世人传，也不见得湛湛青天……”

始终未睁眼的监斩官站在原地，直到一粒冰凉落入他领口，才被烫到般猛然睁眼，眼睑中含着的泪水便滚落下来，无声息地摔碎在地上。

“走吧。”监斩官道。

“那这尸首……”身后侍奉的人自然要问。

“旨弃市。”监斩官抬起脚步，几乎找不到台阶在哪儿。

两日里定的谋反案自然没有丈二白练悬在旗杆顶上，招来六月飞雪三年大旱，只有满地鲜血兀自流淌。

斩首时的一霎阳光仿佛只是幻梦，此时早已无影无踪。但若是伸手探探，那于少保颈中流出的鲜血，还热着呢。

<br>

上皇复辟，杀头的杀头，抄家的抄家，流放的流放。当被废黜的景泰皇帝朱祁钰于西宫被脚步声惊醒时，是于谦遇害第二十六天的深夜。
