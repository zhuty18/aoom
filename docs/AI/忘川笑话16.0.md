# 评《忘川笑语·礼议》——当帝王摘下冕旒，发疯便成了最体面的抒情

读罢此篇，恍若于忘川河畔饮下一壶掺了魏晋五石散的烈酒，初觉喧闹，细品则有丝丝缕缕的悲凉涌入喉头。这并非一出严谨的历史正剧，而是一场盛大的、跨越千年的魂魄狂欢。作者将历代帝王将相投入名为“忘川”的无何有之乡，让他们斗嘴、争辩、钓鱼、落水，甚至认真地讨论如何才能泡到另一位皇帝，其荒诞处令人发噱，其精深处却又足以照见历史书写背后那些被宏大叙事磨损殆尽的人情。

## 剧情安排：嬉笑怒骂，草蛇灰线

文章结构看似散漫，以段子连缀成篇，实则有一条极为清晰的情感主线贯穿始终——赵匡胤对郭荣那点“不值钱的恋王脑”。从金戈馆里荒诞不经的站队投票，到百家书院中关于姓氏的论战；从“朕臣子的臣子不是朕的臣子”所掀开的权力逻辑裂隙，到赵匡胤那段石破天惊的独白——“你但凡有点心肝，也该夸我两句吧”，情节层层递进，将前者那种近乎顽固的单箭头执念烘托到了极致。

作者于叙事节奏的掌控颇为老辣。前半程让众人高谈阔论礼法、国祚与天命，仿佛这真是一场关乎学术与法统的严肃会议；待到赵匡胤发觉自己因为键政而虚度了两个时辰，竟连心上人的消息都忘了回复，整个故事便从“议礼”陡然转向了“泡帝”。这种从形而上到形而下的急转弯，制造了极佳的喜剧效果。结尾的“日后谈”以霍去病为了避嫌兄弟亲昵之风而逃去卫青处收束全篇，四两拨千斤，既呼应了前文无处不在的微妙情愫，又点到为止，余味悠长。

## 人物塑造：解构神坛，魂魄皆有人间烟火

此篇人物塑造最成功之处，在于让历史人物彻底“落地”。郭荣不再是史书上那短短数行“英武之君”的扁平符号，而是一个会晕倒、会抱怨、会一本正经地面试秘书，同时又能对赵匡胤的矫情行径翻出教科书级白眼的真实灵魂。他的魅力甚至跨越了朝代——让汉世宗刘彻在他面前也显得像个捧场的友商，这种“天子中的天子”的侧写，极尽其英武本色。另一边，“二官家”赵匡胤的塑造则堪称一绝。作者将他身上那层“宋艺祖”的金箔揭得干干净净，留下的是一个会花三千两银子买人一笑，会在烂泥里狼狈求救，会病急乱投医到向刘邦、刘询乃至李师师讨教恋爱经验的凡夫俗子。那句“好处说完了，坏处呢”，将他对郭荣那种深入骨髓以至于甘之如饴的沉溺写得淋漓尽致。

配角同样出彩。司马光与王安石对任何问题都能开展原则性辩论，哪怕议题从濮议歪到了皇后待遇，其呆气与固执令人捧腹。杨慎作为唯一一个因为特殊原因被招揽的“正常人”，在这群疯疯癫癫的帝王中艰难地维持着冷静与逻辑，最终却也不得不承认“当皇帝抛出议题的时候，他的立场已经明确了”，完成了对自身历史命运的顿悟与自嘲。

## 写作手法：跨时空的群口相声与现代性的解构

作者熟练运用了“跨时空群像喜剧”这一极具现代感的创作手法。将不同朝代、原本绝无可能同框的人物并置于忘川这个时空模糊地带，利用他们之间的信息差、价值观冲突与文化语境错位，制造了无数精妙的笑料。例如嬴政与韩非讨论荀门学风与鬼谷校规，信手拈来的梗密集到令人发指；曹植陪着李煜，只因后者听到郭荣的声音就想起童年阴影，这种将惊悚化为幽默的笔触，需要十分渊博的掌故储备方可为之。

对历史事件的解构与再诠释是全篇的灵魂。礼议本身是关于名分、法统的无尽争吵，文中却通过杨慎之口点破天机——这从来不是礼法问题，而是立场问题。然而，在忘川的语境里，连立场都被消解了。因为“陛下”也好，“官家”也罢，所有尊卑在死后都失去了重力。当郭荣被孙思邈勒令躺下，当赵匡胤在韩信鱼钩上挣扎时，历史赋予他们的一切盔甲都自然脱落，只剩个体与个体之间最为直接的情感碰撞。

## 文笔：风骨俊爽，于雅俗间从容游走

此文笔法有宋人笔记小说的俊爽利落，又不失现代网络文学的鲜活灵动。对话是本篇的骨干，几乎完全依靠语言推动情节，且极富个性化——王安石言必称变革与反驳，司马光开口即是训诂考据，苏轼圆融而多智，霍光则端谨之中自有不动声色的诙谐。古语与今言自由切换，毫无滞涩。如“恋王脑”、“键政”等现代词汇的混用，非但不显突兀，反而因指涉精准而产生了强烈的间离与戏仿效果，让这些亡魂同时兼具了古人的骨相与今人的皮相。

仅有一处小疵：某些过渡性场景依赖读者对前后文的快速理解，信息密度过高，初次阅览或许微觉眼花缭乱。

## 感情戏码的张力：发疯是弱者的幻想，亦是强者的投降

表面是笑话集，底色却是极为深沉的意难平。赵匡胤与郭荣之间所有情感牵引的核心，都在那艘驶往忘川对岸的小船上。赵匡胤说：“我给你打下来。”语气轻描淡写，却是一个迟到千年、永远无法兑现的承诺。他所有的恋王脑，所有上蹿下跳的骚扰短信与死乞白赖，都是对生前“矫诏篡位”那一刻的永恒追悔。郭荣那句“朕要的燕云十六州呢”，是横亘在他心头的一根刺，而忘川里没有仗可打，所以他的补偿便只能化作一种近乎卑微的祈求：做你的皇后，结拜为兄弟，至少，你回我一条消息。

郭荣的态度则更耐人寻味。他的怨气是真，但他在乎也是真。否则不会在看到赵匡胤的表白短信时展颜一笑，不会用“再议”这样暧昧的词来收尾。白起对赵匡胤说“这种人阴魂不散的……活着你是他的人，死了还得当他的鬼”，恰是对这份关系最精准的注脚：它是一种宿命般的绑定，超越了君臣、敌友，甚至爱恨。最终二人乘船出海探索未知，“赵匡胤，跟我来”、“好嘞”，这是介于君臣命令与生死相随之间的应答，其简洁与默契，恰与开篇十几位文人争论“姓氏”的喧嚣场景形成闭环——名分终是虚妄，而相伴渡河、开拓未知才是本质。将帝王心术与私人情感的博弈，藏在一个笑话的壳里，这是那杯龙舌兰底部的虫，是整杯酒的味道之源。这或许是最能保有帝王体面的回应，但也恰是在这个悬浮于生死之间的世界里，他才终于允许自己给彼此一个还未被历史定性为乱臣与故主的未来。

当帝王不再是帝王，臣子不再是臣子，那些被权力异化扭曲的关系，终于有可能还原为其本来该有的样子——或许是一对互相责备又互相依赖的故人，或许是一对在忘川河畔，同乘一舟的钓客。

总而言之，这是一篇需要带着百科知识和幽默感来阅读的佳作。它用最不正经的方式，讲了一个最正经不过的道理：所谓历史，终究是人的历史；而人之常情，哪怕是帝王，也不过是想得到所念之人的一声回应罢了。
